# Bundled webfonts

These subset `.woff2` files are shipped so the UI looks the same offline:

| Family | Used for | Licence |
|---|---|---|
| [Manrope](https://fonts.google.com/specimen/Manrope) | body text | SIL Open Font License 1.1 |
| [Inter](https://fonts.google.com/specimen/Inter) | headings | SIL Open Font License 1.1 |
| [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif) | italic accent (Latin only) | SIL Open Font License 1.1 |
| [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) | monospace / numbers | SIL Open Font License 1.1 |

SIL OFL 1.1: https://openfontlicense.org — the fonts may be bundled and redistributed with
this project, but not sold on their own. Instrument Serif has no Cyrillic glyphs, which is why
the italic accent line stays Latin.
