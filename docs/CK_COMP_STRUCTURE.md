# Структура Fusion-композа CorridorKey

Сборка композа скриптом (`resolve_compose.py`) на 21.1 упирается в API Resolve: связи,
поставленные через `SetInput`, применяются через раз, а `AddTool` раскидывает ноды на
десятки тысяч пикселей. Рабочий приём — **не строить ноды по одной, а вставить готовый
текст композа в буфер обмена и вызвать `comp.Paste()`**: ноды появляются компактно на
текущем виде и со всеми связями из текста. Формат — Fusion copy-format
(`Tools = ordered() { ... }`).

## Граф (минимальная рабочая структура)

```
ck_fg  (Loader, EXR RGBA) ─┐
                           ├─► ck_merge (Merge) ─► MediaOut1
ck_bg  (Loader, PNGсекв.) ─┘
```

Плашка отдельным нодом не нужна: `MediaIn1` в композе клипа уже даёт кадр клипа, а
`Loader` mp4 не читает. Если нужен именно исходник внутри графа — берите `MediaIn1`.

Позиции (компактно, чтобы всё влезало в один экран графа без масштабирования):

| нода      | тип    | Pos (x, y) | входы                                  |
|-----------|--------|------------|----------------------------------------|
| ck_bg     | Loader | 0, 130     | Clip = PNG-секвенция фона, кадры 0…N-1  |
| ck_fg     | Loader | 0, −130    | Clip = EXR-секвенция fg (RGBA), 0…N-1   |
| ck_merge  | Merge  | 260, 0     | Background ← ck_bg, Foreground ← ck_fg |
| MediaOut1 | MediaOut | 480, 0   | Input ← ck_merge                       |

`ck_alpha`/`ck_matte` (MatteControl с `Garbage.Matte`) нужны только если у fg нет альфы:
у CorridorKey fg — RGBA, поэтому MatteControl в граф не ставим (именно он раньше давал
сплошной чёрный вокруг субъекта).

## Как вставить граф в клип

1. Плейхед на клипе таймлайна, открыть страницу Fusion.
2. Положить текст композа в буфер (см. `resolve/compose_template.py`, функция `copy_format`).
3. `comp.Paste()` (или Ctrl+V в графе).

Проверка: `comp.GetToolList()` → ровно 4 ноды (`ck_bg`, `ck_fg`, `ck_merge`, `MediaOut1`).

## Что нельзя делать

- `AddTool(regid, x, y)` — координаты в других единицах (1 ≈ 14 600 px), ноды улетают
  «за километр», руками их потом не собрать.
- `comp.Save()` без аргумента — открывает диалог «Save File» и вешает скрипт.
  Сохранять проект: `projectManager.SaveProject()`.
- `ImportFusionComp()` для композа с `Loader`: Resolve конвертирует лоадеры в `MediaIn`,
  то есть внешние файлы теряются.
- Держать десятки нод в одном композе: чистка (`DeleteFusionCompByName`, `DeleteTool`)
  не работает, композиции не удаляются.

## Открытый дефект (21.11, 4K)

После вставки графа на 4K-клипе Deliver отдаёт субъект **на чёрном фоне**: `ck_bg` в
Merge не попадает (сам Loader фон рисует — проверено отдельно). Нужно проверить в UI:
выбрать `ck_merge` → вход Background должен быть жёлтым и идти от `ck_bg`; если он
чёрный — протянуть `ck_bg` вручную. После этого прогнать Deliver и сверить пиксели:
у градиента `--bg4k` средний BGR ≈ (129, 89, 114), у чёрного ≈ (13, 2, 6).
